# 李志 · 想听就听 — iPhone 移动版

一个独立的、无需 Windows EXE 的静态 Web 音乐播放器，适配 iPhone Safari，可添加到主屏幕。

## 支持功能

- 根据原 `nj-lizhi/song` 项目的 `list-v2.js` 在线曲库载入歌曲、专辑与封面
- 全曲库浏览、搜索歌曲和专辑、专辑筛选、现场筛选
- 收藏歌曲（保存在当前浏览器本地，不跨设备同步）
- 播放/暂停、上一首/下一首、进度跳转、随机播放、列表循环/单曲循环
- iOS Media Session 元数据与系统媒体控制尝试接入
- 适配刘海屏安全区、主屏幕图标和独立窗口（PWA）
- 三个曲库脚本地址依次回退，曲库连接失败时显示重试按钮

## 立即部署到 GitHub Pages（不用安装 Node.js）

1. 登录 GitHub，新建一个**公开**仓库（例如 `lizhi-mobile`）。
2. 将本文件夹内全部文件（`index.html` 等）上传到仓库**根目录**。
3. 进入仓库 **Settings → Pages**，选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`，保存。
4. 页面发布后，访问 `https://你的用户名.github.io/lizhi-mobile/`。
5. iPhone Safari 打开网站，点**分享 → 添加到主屏幕**。

注意：Pages 发布可能需要一段时间。要更新网页，替换 `index.html` 等文件后重新提交。

## 本地电脑预览

在本目录运行：

```bash
python -m http.server 8000
```

再用浏览器打开 `http://localhost:8000`。若要在 iPhone 上用同一 Wi-Fi 访问电脑，请用电脑局域网 IP 而非 `localhost`。iPhone PWA/媒体权限建议用 HTTPS 的正式部署地址测试。

## 使用限制

- 播放使用**现有第三方远程音频链接**，本项目不保存任何音乐文件，也不保证第三方资源长期可用。
- 首次打开和加载曲库需要网络连接，离线时 PWA 界面可能可打开，但无法保证音频能播放。
- Safari 中后台播放、锁屏显示、蓝牙控制是否生效，依赖 iOS 版本、音频格式和源站响应；需真机测试。
- `list-v2.js` 中包含部分 FLAC；若 iOS/浏览器不支持某文件或源站拒绝访问，播放器会提示错误。
- 当第三方曲库的加载脚本/音频链接变化时，需要更新源地址。
- 歌曲数据脚本由原第三方提供，请自行判断网络可用性、音乐内容授权和公开部署的合规性。
